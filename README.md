# やるぞ！

ADHD 当事者のための「着火装置」。タスク管理アプリではありません。

画面に出るのは **次にやる 1 件だけ**。押せばタイマーが回り始める。それだけのアプリです。
名前は起動の合図そのもので、「やるぞ！」と思った瞬間に立ち上げることを想定しています。

- 説明ページ: <https://yaruzo-self.vercel.app/about>
- web 版（そのまま触れます）: <https://yaruzo-self.vercel.app>

## なぜ作ったか

ADHD の脳は「重要かどうか」では動き出しにくく、興味・新しさ・挑戦・緊急性で動く
（興味ベース神経系）と言われます。一般的な ToDo アプリが前提にしている
「全部並べて、優先度順に片付ける」は、この脳にはむしろ逆効果になりがちです。

- 全体量が見えると固まる → **1 件しか見せない**
- 重要度で並べても動けない → **優先度・重要度の概念を持たない**
- 計画を立てると未達が生まれる → **時間割や目標値を作らない**
- 連続記録が途切れると恥ずかしくなってアプリごと放棄する → **連続日数を出さない。累積だけ数える**
- 2 日で飽きる → **完了時の一言や名言をランダムにする**

設計の根拠と全画面の仕様は [DESIGN.md](DESIGN.md) にまとめています。

## できること

| キー | 操作 |
| --- | --- |
| `Space` | タイマー開始 / 一時停止（経過時間をカウントアップ表示） |
| `Enter` | 完了 |
| `N` | タスクを追加 |
| `D` | 分解 — 大きすぎて手が出ないタスクを 3 つの小さな手順に割る |
| `P` | いったんやめる — いまの 1 件を外して次を出す |
| `S` | 眠い — 歩く・水を飲む・顔を洗う などの身体タスクを出す |
| `T` | 今日 — 完了一覧、累積カウンタ、起床時刻・光を浴びたかの記録、今日の約束 |
| `Esc` | 開いている画面を閉じる |

マウス・タッチでも同じ操作ができます。

- **出る順番** は古い順の先頭 1 件。抽選も重要度ソートもしません。気が乗らなければ `P` で送ります
- **定番** — 歯磨き・日報のような繰り返しの用事を登録しておくと、追加画面から 1 タップで生えます
- **目安分** — タスクのバッジを上下にドラッグ（または上下キー）で 5 分刻みに変えられます
- **今日の約束** — 会議・通院・締切など、外から来て動かせない予定を今日の分だけ置けます。
  画面右に時刻順で出て、次の 1 件に残り時間が付きます。タスクとは紐付けず、守れたかも問いません

### 意図的に作っていないもの

優先度ソート、タグ・フィルタ、カレンダー同期、連続ストリーク、達成率グラフ、
通知・催促、ログイン・同期、設定画面。

どれも「管理作業を増やす」か「罪悪感を生む」ので外しています。理由は [DESIGN.md](DESIGN.md) 7 章。

## データについて

すべてのデータはブラウザ（またはデスクトップアプリ）の **IndexedDB の中だけ** に保存されます。
サーバ・アカウント・外部サービスは一切使いません。別の端末には引き継がれません。

## 動かす

Node.js（`.ts` をフラグなしで直接実行できるバージョン。v24 以降で確認）が必要です。

```bash
npm install
npm run dev     # http://localhost:3000
```

### デスクトップアプリとしてビルドする（Windows）

[Tauri](https://tauri.app/) でデスクトップアプリにしています。Rust と Microsoft C++ Build Tools が別途必要です
（手順は [SETUP.md](SETUP.md) 1 章）。

```bash
npm run tauri build
```

`src-tauri/target/release/bundle/nsis/` にインストーラが出ます。
macOS / Linux でもビルドできる構成ですが、動作確認はしていません。

### テストなど

```bash
npm test        # node --test（追加依存なし）
npm run lint
npm run build
```

## 技術構成

- Next.js（App Router, 静的エクスポート）+ TypeScript + Tailwind CSS
- 永続化: IndexedDB
- デスクトップ: Tauri 2
- web 版: Vercel

```text
app/page.tsx             メイン画面（NOW）
app/overlays.tsx         追加 / 分解 / 眠い / 今日 の各画面
lib/types.ts             データ形状の定義
lib/store.ts             IndexedDB の読み書き（ここに集約）
lib/select.ts            次の 1 件を選ぶロジック
lib/quotes.ts            名言
public/about/index.html  説明ページ（/about）
src-tauri/               デスクトップアプリの殻
```
